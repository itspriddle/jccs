# jccs - Josh's Claude Code Statusline

Claude Code statuslines are a dime a dozen. This one is mine. Use it or don't.

![](docs/assets/screenshot-v0.1.0.png)

## Install

```sh
cargo build ...
cp jccs ~/.claude/
~/.claude/jccs install
$EDITOR ~/.config/jccs/config.toml
```

## Uninstall

```sh
~/.claude/jccs uninstall
rm ~/.claude/jccs
```
